# 《메이플크래프트 : 마지막 모험가》 환경설정(SettingsUI) 전용 구현 명세서

본 문서는 **1920 × 1080 (16:9 FHD)** 해상도 기준 **환경설정(`SettingsUI`)** 화면의 레이아웃 규격과 전용 커스텀 UI 리소스(에셋 10 ~ 12, 개별 분할 12종) 적용 가이드입니다.

---

## 2. 좌·우 페이지 세부 컴포넌트 구현 지시사항

### 2.1. 좌측 페이지 (`LeftPage_SafeArea` — 사운드 설정 & 화면 설정)

1. **섹션 1 (`사운드 설정`)**:
   * 상단에 소제목 `사운드 설정`(진한 고동색 `#3B2314`, Bold) 또는 소형 나무 리본 배너(`12a_UI_Header_SectionSubBanner`)를 배치합니다.
   * `배경음 (BGM)` 및 `효과음 (SFX)` 2개 행을 단일 페이지 폭 카드 배너(`380 × 76 px`, 행 간격 `12 px`) 위에 배치합니다.
   * **사운드 행 내부 구성**:
     * 좌측: 음소거 토글 아이콘 버튼 (`10d_UI_Btn_Sound_On` / `10e_UI_Btn_Sound_Mute`, 크기 `38 × 38 px`)
     * 라벨: `배경음` / `효과음` (폭 `68 px`, 좌측 정렬)
     * 볼륨 슬라이더: 빈 우드 트랙(`10a_UI_Slider_Track_Empty`, `180 × 22 px`) + 그린/골드 채움 바(`10b_UI_Slider_Bar_Filled`, `FillAmount` 연동) + 원형 나무 노브(`10c_UI_Slider_Handle_Knob`, `30 × 30 px`)
     * 우측 수치: `0% ~ 100%` 텍스트 (폭 `48 px`, 우측 정렬)
   * **인터랙션**: 좌측 스피커 버튼 클릭 시 즉시 음소거 상태(`10e` 아이콘 교체 및 볼륨 0%)로 전환되며, 재클릭 시 직전 볼륨값으로 복원됩니다.

2. **섹션 2 (`화면 설정`)**:
   * 하단에 `화면 설정` 소제목을 배치하고, `화면 흔들림`, `채집 알림` 2개 행을 카드 배너(`380 × 68 px`, 행 간격 `12 px`)로 배치합니다.
   * 각 행 우측 끝에 ON/OFF 슬라이드 스위치(`11a_UI_Toggle_Switch_On` / `11b_UI_Toggle_Switch_Off`, 크기 `84 × 38 px`)를 배치하여 클릭 시 상태를 전환합니다. (필요 시 체크박스 `11c`/`11d`로 대체 가능)

### 2.2. 우측 페이지 (`RightPage_SafeArea` — 조작키 설정 & 초기화/저장)

1. **섹션 3 (`조작키 설정`)**:
   * 상단에 `조작키 설정` 소제목을 배치하고, 아래 4개 행을 카드 배너(`380 × 68 px`, 행 간격 `12 px`)로 수직 배치합니다:
     1. `이동 / 점프`: 우측에 와이드 키캡 배지(`12c_UI_Badge_Keycap_Wide`, `96 × 38 px`) 배치 후 `방향키` 텍스트 표시.
     2. `채집 / 상호작용`: 우측에 와이드 키캡 배지(`12c_UI_Badge_Keycap_Wide`, `96 × 38 px`) 배치 후 `Space` 텍스트 표시.
     3. `인벤토리 / 제작`: 우측에 정사각 키캡 배지(`12b_UI_Badge_Keycap_Square`, `38 × 38 px`) 2개를 배치하여 `I` / `C` 표시.
     4. `스킬 슬롯`: 우측에 정사각 키캡 배지(`12b_UI_Badge_Keycap_Square`, `38 × 38 px`) 4개를 나란히 배치하여 `Q` `W` `E` `R` 표시.

2. **하단 버튼 영역**:
   * 우측 페이지 하단에 `초기화`(회갈색 보조 버튼, `176 × 52 px`)와 `설정 저장`(올리브그린 주 행동 버튼, `176 × 52 px`)을 나란히 배치(`Spacing: 20 px`)합니다.
