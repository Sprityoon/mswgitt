# 현재 게임 톤앤매너 기반 HUD 및 전체 팝업 UI(07\~51, 총 45장) 확장·수정 최종 마스터 지침서 (Agent Handoff Spec v6)

본 문서는 현재 게임의 고유한 분위기(**둥근 브라운 우드 헤더/푸터 + 부드러운 크림 양피지 본문 + 다크 브라운 라운드 슬롯 + 직관적인 사각/라운드 HUD 버튼 배치**)를 **그대로 유지하면서**, 1\~5차에 걸쳐 전달된 전체 45장의 인게임 UI 화면(`07_hud_town.jpg` \~ `51_chat_expanded.jpg`)을 일관된 톤으로 통일하고 좌표 오류·렌더링 버그·텍스트 잘림·가독성 결함을 바로잡기 위한 **코딩/UI 에이전트 전용 최종 마스터 구현 명세서**입니다.

> **핵심 원칙 및 예외 규칙 (Core Principles & Exclusions)**:
>
> 1. **개발 테스트 전용 UI는 수정 제외 (Skip Dev Tools)**:
>
>    * `47_preview_tool_dev.jpg` (`리소스 프리뷰 — 아바타 + 아이템`) 및 `41_skill_tooltip_and_test_hud.jpg` 좌하단의 `TEST MODE` 디버그 오버레이는 개발/테스트 전용 도구이므로 UI 디자인 개편 대상에서 \*\*제외(현행 유지)\*\*합니다.
>
> 2. **하단 10칸 퀵슬롯(핫바) 외곽 크기 유지 + 내부 가독성만 강화**:
>
>    * 하단 10칸 퀵슬롯 바의 **외곽 프레임 크기(가로·세로 사이즈)는 현재 상태 그대로 유지**합니다(크기를 키우면 하단 시야와 좌우 컨트롤러 영역을 침범함).
>
>    * 대신 슬롯이 작아 보였던 원인인 **내부 단축키 숫자(`1`\~`0`, 좌상단)와 보유 수량 숫자(우하단)의 폰트 크기를 `8~9px` → `12px Bold`(+ 검은 외곽선 `text-shadow`)로 키우고**, 내부 아이템 아이콘 스케일을 `75%` → `85%`로 살짝 채워 넣어 외곽 크기 변경 없이 시인성만 2배 높입니다.
>
> 3. **낚시(`릴링!`) 게이지는 화려한 그라데이션 없이 깔끔한 단색(Solid Flat Color) 적용**:
>

>
> 4. **외부 플로팅 패널 내부 편입 & 다크/남색 창 브라운+양피지 통일**:

## 1. 5차 마지막 화면(`46` \~ `51`) 및 추가 피드백 반영 상세 명세

### 1.1 \[피드백 반영\] 낚시 게이지 깔끔한 단색화 & 하단 10칸 퀵슬롯 내부 가독성 개선 (`44`\~`45` → `26_fishing_gauge_refined.png`)

1. **낚시(`릴링!`) 게이지 — 깔끔한 단색(Solid Flat) 캡슐 바 적용**:

   * 화려한 그라데이션이나 아이콘 장식을 배제하고, 좌상단 HP/MP 바와 동일한 **플랫 캡슐 바 스타일**로 통일합니다.

   * **트랙(배경)**: 1행·2행 모두 `#2A1B12` (`border-radius: 999px`)로 지정해 채워진 양(Fill %)이 명확히 대비되게 합니다.

   * **1행 (릴링 진행도 바, 높이 `14px`)**: 단색 웜 앰버 골드(`#E5A93B`)로 깔끔하게 채웁니다.

   * **2행 (장력/위험도 바, 높이 `10px`)**: 평상시(`44`)에는 차분한 크림 아이보리(`#EAE0D5`) 단색으로 차오르다가, 위험 임계치(`45`, `※ 위험! 손을 떼세요!`) 도달 시 단색 코랄 레드(`#D9483B`)로 바 색상이 전환되도록 처리합니다.

2. **하단 10칸 퀵슬롯(핫바) — 외곽 사이즈 동결 & 내부 텍스트/아이콘만 확대**:
