## 사용 기준

맵에 등록할 기본 파일은 **sprites/**다. 고해상도 **masters/**는 추가 수정이나 큰 화면 용도이며, 같은 모델 Scale을 그대로 적용하면 크기가 달라진다. 두 버전을 함께 같은 크기의 오브젝트로 등록하지 않는다.

게임용은 3px 단위 도트 마감, 디더 없이 색상 제한(나무 48·유카 56·두개골 40색 상한), 내부 고립 명암 정리를 적용했다. 초기 권장 Scale은 세 종류 모두 **0.5**이며 화면 도트 굵기는 1.5px다. 실제 불투명 영역은 나무 약 248×273px, 유카 약 183×197px, 두개골 약 120×102px로 보인다. 배율과 콜라이더는 아직 모델에 연결하지 않은 시작값이다.

원본의 나무 줄기·가지·뿌리, 유카 잎과 크림색 꽃대, 왼쪽 아래를 향한 두개골·두 뿔·안와·비강을 유지했다. 배경·문구·색상 견본·모래 지면·바닥 그림자는 포함하지 않았다. 생성 PNG의 거의 투명한 외곽 픽셀(alpha≤16)은 RGB와 알파를 정리하고, 고해상도 본체의 나머지 부분 알파는 보존했다. 게임용 알파는 0/255다.

## 원본 및 재출력

- `source.jpg`: 참조 원본 복사본, 루트 원본과 SHA-256 일치 확인.
- `generated/`: image_gen의 독립 리드로우 결과 3장, 원본 생성 파일은 별도로 보존했다.
- [brief.md](brief.md): 변환 브리프와 구도·규격.
- [prompts.json](prompts.json): 실제 생성 프롬프트 3개. 내장 image_gen 사용, CLI/API 생성 미사용.
- [export.cjs](export.cjs): 투명 PNG 추출·정렬·도트 마감·아이콘·합성 미리보기의 재현 가능한 출력 도구. 외부 패키지 설치가 필요 없다.
- `manifest.json`: 파일 대응·해시·해상도·권장 배율·피벗·불투명 bbox.

프로젝트 루트에서:

```powershell
node docs/design/art/desert/redraw_v2/export.cjs
node docs/design/art/desert/redraw_v2/export.cjs verify
```

## 검토 결과와 적용 범위

- 1차: 세 정체성·원본 각도·투명 배경·잘리지 않은 가지/잎/뿔 및 지형 위 읽힘 확인. 도트 마감의 잔색과 거의 투명한 외곽 색 잔여를 보완 대상으로 선정했다.
- 2차: 팔레트를 줄이고 고립된 내부 명암을 정리, 낮은 알파 외곽 정리 후 체커/잔디/흙/눈에서 재검토. 부드러운 재질과 세부 묘사를 보존하면서 게임용 윤곽을 확인했다.
- PNG 9장 해시·투명 코너, 게임용 규격·이진 알파, 하단 여백 2px·중앙 X 오차 ≤2px·위/좌우 여백 ≥2px 검증 통과. 아이콘의 가운데 배치도 확인했다.
- 이 작업은 **아트 산출물 제작**이며 모델·맵·tileset·RUID를 수정하지 않았다. Maker 등록과 모델 연결은 별도 작업이다. 계정 리소스 업로드는 수행하지 않았다.
- Maker 도구가 이 세션에 노출되지 않아 **refresh 검증 보류**. **런타임 검증 보류(제작자 수행)**: Sprite 등록 후 실제 배율·Y정렬·뿌리 접지선·콜라이더 일치 확인.
