# 사막 환경 소품 3종 고해상도 리드로우 브리프

- **원본**: 프로젝트 루트 `B9D01CA8-2232-44EA-A253-509D92DD8341.jpg`. 첨부 로딩은 실패했으나 로컬 파일을 찾아 직접 확인했다.
- **대상**: 마른 나무, 꽃이 핀 유카, 뿔 달린 동물 두개골. 각각 독립된 투명 PNG로 제작한다.
- **제작 방식**: image_gen 참조 리드로우 → 투명 영역·실루엣 확인 → 개별 PNG 추출/정렬 → 게임용 약한 도트 마감 → 지형 위 시각 검토. 저해상도 JPEG를 단순 확대하지 않는다.
- **공식 리소스 판정**: 제작자의 특정 원본 리드로우 요청을 우선한다. 공식 리소스로 형태를 대체하지 않는다.

## 규격과 구도

- 트랙 A: 메이플 카툰 셀 명암과 약한 도트 마감. 원본 시점과 각도를 유지하고 좌상단 광원을 통일한다.
- 독립 고해상도 원본은 생성 해상도로 보존한다. 게임용 출력은 나무 512×640, 유카 384×448, 두개골 256×224를 기준으로 한다.
- 게임용 구도 계약: 하단 중앙 피벗, 바닥 여백 0~2px, 불투명 실루엣 중심 X 오차 ≤2px, 위·좌우 여백 ≥2px.
- 권장 초기 배율과 도트 간격: 나무 0.5·3px, 유카 0.5·3px, 두개골 0.5·3px. 화면에서 도트 1.5px. 배율은 아직 모델에 적용하지 않은 시작값이며 Maker에서 이웃 오브젝트와 비교한다.
- 텍스트·색상표·테두리·배경·바닥의 모래 및 흩어진 작은 돌·굽힌 바닥 그림자는 제외한다. 나무 뿌리와 유카의 기부는 보존한다.
- 시각 기준: 기존 `furnace_idle.png`의 따뜻한 외곽선과 도트 밀도, 겨울 나무의 읽히는 자연물 덩어리. 실제 게임 배율의 잔디·흙·눈에서 최소 두 차례 검토한다.
- 기존 `docs/design/art/desert/`의 추출 파일 및 다른 에이전트의 작업을 덮어쓰지 않고 `redraw_v2/`에 저장한다.
