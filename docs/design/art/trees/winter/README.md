## 4. 모델(.model) 등록 및 인계 절차

> **규칙 45 (Pitfalls)**: 외부 스크립트로 임의 등록한 스프라이트 리소스는 런타임에서 `RUID is unavailable` 오류가 발생하므로, 반드시 Maker의 공식 UI를 통해 가져와야 합니다.

1. **Maker 리소스 가져오기**:
   - MSW Maker 실행 -> 상단 `[내 리소스] -> [가져오기]` 클릭
   - [`docs/design/art/trees/winter/trees/`](file:///d:/메이플월도/docs/design/art/trees/winter/trees/) 및 [`props/`](file:///d:/메이플월도/docs/design/art/trees/winter/props/) 폴더의 27개 PNG 이미지를 일괄 선택하여 임포트합니다.
2. **피벗 설정**:
   - 모든 에셋의 피벗을 `Bottom Center` (하단 중앙)으로 지정합니다. (타일 바닥면 접지 기준)
3. **RUID 일괄 동기화 및 모델 완성**:
   - Maker에서 발급된 RUID를 [`scratch/winter_sprites_ruid_map.json`](file:///d:/메이플월도/scratch/winter_sprites_ruid_map.json) 파일에 아래 형식으로 입력합니다:
   ```json
   {
     "tree_winter_01_basic": "발급된_RUID_1",
     "tree_winter_02_tall": "발급된_RUID_2",
     ...
     "prop_winter_09_fallen_leaves": "발급된_RUID_27"
   }
   ```
   - 스크립트 실행: `node scripts/create_winter_trees_and_props.cjs`
   - 이미 27개의 `.model` 골격이 [`RootDesk/MyDesk/MapObjects/Models/`](file:///d:/메이플월도/RootDesk/MyDesk/MapObjects/Models/) 폴더에 생성되어 있으므로, RUID가 주어지면 자동으로 실제 스프라이트가 즉시 연동됩니다!
