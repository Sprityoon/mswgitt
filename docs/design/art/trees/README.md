### [형태 1] 키 큰 원뿔형 전나무 (Tall Conifer Pine)
- **실루엣 특징**: 위로 곧게 솟은 4단 층상의 뾰족한 삼각형/원뿔형 실루엣
- **추천 배치**: 마을 외곽 경계선, 성벽길, 방풍림, 언덕 위
- **에셋 목록**:
  - `1-A. 신록 에메랄드 전나무`: [`form1_tall_pine_green.png`](file:///d:/메이플월도/docs/design/art/trees/variations/form1_tall_pine_green.png)
  - `1-B. 설산 겨울 눈꽃 전나무`: [`form1_tall_pine_snow.png`](file:///d:/메이플월도/docs/design/art/trees/variations/form1_tall_pine_snow.png)

### [형태 2] 다간형 덤불 정원수 (Multi-Trunk Grove Tree)
- **실루엣 특징**: 3~4개의 가는 나뭇가지가 바닥에서부터 부채꼴로 뻗어 올라가 자연스러운 숲을 이루는 유기적 수형
- **추천 배치**: 마을 중앙 공원, 오솔길 산책로, 화단 및 텃밭 주변
- **에셋 목록**:
  - `2-A. 신록 다간 정원수`: [`form2_multitrunk_green.png`](file:///d:/메이플월도/docs/design/art/trees/variations/form2_multitrunk_green.png)
  - `2-B. 붉은 산열매/베리나무`: [`form2_multitrunk_fruit.png`](file:///d:/메이플월도/docs/design/art/trees/variations/form2_multitrunk_fruit.png) (잎사귀 사이에 달콤한 붉은 베리가 맺힘)

### [형태 3] 우아한 곡선 소나무 (Curved Bonsai Pine)

- **추천 배치**: 연못가, 낚시터, 정자 마당, 고급 가옥 앞마당 포인트 조경목

## 3. MSW Maker 등록 및 인계 안내

> **규칙 45 (Pitfalls)**: 외부 스크립트로 임의 등록한 에셋은 런타임 오류가 발생할 수 있으므로, 반드시 Maker UI를 통해 안전하게 등록하십시오.

1. **Maker 리소스 가져오기**:
   - MSW Maker 실행 -> 워크스페이스 상단 `[내 리소스] -> [가져오기]` 클릭
   - [`docs/design/art/trees/variations/`](file:///d:/메이플월도/docs/design/art/trees/variations/) 폴더의 에셋들을 선택하여 등록합니다.
2. **피벗 설정**:
   - 각 스프라이트의 피벗을 `Bottom Center` (하단 중앙)으로 지정합니다.
3. **모델 생성 및 맵 배치**:
   - 기존 [`Tree1.model`](file:///d:/메이플월도/RootDesk/MyDesk/MapObjects/Models/Tree1.model)을 복제한 뒤 각각의 모델(예: `Tree_TallPine`, `Tree_GroveFruit`, `Tree_SpreadingBlossom` 등)을 생성하고 마을 맵에 배치합니다.
