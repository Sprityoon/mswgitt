# 목재·회벽 벽 연결 타일 16종

기존 `woodland_64/tileset_64@3x.png`를 내장 이미지 생성 도구에 실제 첨부하여 제작했다. 제작자 지정 그림체·4×4 구성·연결 순서·마젠타 배경을 기준으로 새 벽 시트를 제작하고, 생성물의 불일치 부분을 PXG 기반으로 정리했다. 공식 리소스 대체가 아닌 제작자 지정 참조의 신규 아트 요청이다.

- 최종 시트: [wall_16_64.png](./wall_16_64.png), 256×256px, 4×4, 한 칸 64×64px.
- 확대 보기: [wall_16_64@4x.png](./wall_16_64@4x.png), 1024×1024px, 최근접 4배.
- 개별 파일: `tiles/wall_01.png`~`wall_16.png`, 각 64×64px, 위에서 아래/왼쪽에서 오른쪽 순서.
- 배경: 불투명 단색 `#FF00FF`, 투명 배경이 아니다. 선·격자·번호를 시트에 넣지 않았다.
- 원본: `generated_source.png`, `generated_source.pxg`, 최종 픽셀 원본 `wall_16.pxg`, 재현 스크립트 `finish_wall_grid.cjs`.
- 내장 이미지 생성 프롬프트: [generation_prompts.txt](./generation_prompts.txt).

## 연결 순서

N=위, E=오른쪽, S=아래, W=왼쪽. 번호는 파일 이름/문서에만 있고 그림에는 없다.

| 행 | 1열 | 2열 | 3열 | 4열 |
|---|---|---|---|---|
| 1 | 01 없음 | 02 N | 03 E | 04 N+E |
| 2 | 05 S | 06 N+S | 07 E+S | 08 N+E+S |
| 3 | 09 W | 10 N+W | 11 E+W | 12 N+E+W |
| 4 | 13 S+W | 14 N+S+W | 15 E+S+W | 16 N+E+S+W |

## 정리·검수

1차 생성 비평: 남쪽 연결이 끝단으로 그려지고, 일부 돌받침 하단에 여백이 생기는 문제를 수정 요청했다.
2차 생성 비평: 가로 직선 중앙 기둥은 제거됐지만 남쪽 연결과 셀 경계가 여전히 불일치했다. 생성된 목재·회벽·돌 픽셀을 재사용하여 연결별 출구와 명암 밴드를 PXG로 고정했다.
추가 픽셀 비평: 세로 목재의 반복 가로띠를 제거하고 세로 나뭇결로 정리했다. 접합부 위에서 명암 띠가 끊기는 덮임 순서를 수정했다.

가로 면은 y=13~63(약 80%), 목재13~25·회벽26~49·돌50~63. 세로 단면은 x=11~52(42px, 약 2/3폭). 이어지는 좌우 단면과 남북 단면은 각각 공통 픽셀 프로필을 사용한다. 없는 북/동/서 출구, 남쪽 출구, 16종 마스크, 발끝 하단 정렬, 치수·알파를 정적 검사했다. 남쪽으로 이어지지 않는 전면의 돌받침도 지시대로 최하단에 있으므로 **최하단 불투명 픽셀 자체가 S 연결을 뜻하지 않는다.** 논리 연결은 위 표를 따른다.

PNG 규격 및 연결 단면 검증은 통과했으나, 실제 Maker 조립/타일 충돌/월드 배율 검증은 수행하지 않았다. 게임 파일·타일셋·테스트 설정은 이번 아트 작업에서 변경하지 않았다.
