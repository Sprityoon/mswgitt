## 구조

기존 16마스크 N1/E2/S4/W8 순서(0~15) 유지. 앞면은 S 없는 8칸에만 35px, 나무 테두리는 없는 N/E/W 변에만 3px. 윗면끼리 연결되는 내부에 기둥·보가 없다.

## 비평·검증 범위

1차 모델 결과는 손그림 목재·회벽·돌 재질을 얻었지만 행 높이와 앞면 위치가 달라졌다. 2차 생성에서는 부드러운 채색을 유지하며 좌표와 띠 위치를 다시 요청했다. 여전히 생성 시트 행 높이가 달라, 그림 자체를 유지한 채 재질 부품을 공통 4×4 정사각형 배열에 배치했다.

최종 마스터와 실제 64px 게임 크기 시트를 눈으로 대조해 픽셀 블록 없이 회벽 명암·목재 결·돌의 둥근 형태가 남는 것을 확인했다. 치수·알파·8개 공통 앞면·완전 연결 칸의 전체 윗면은 스크립트 검사 통과. 부드러운 크기 변환 때문에 64px 경계 픽셀에는 색 혼합이 생길 수 있으므로 앞선 PXG 시트의 픽셀 단위 공유 경계 검사 결과를 이 버전에 적용하지 않는다. 실제 조립·경계 확인은 제작자 수행.
