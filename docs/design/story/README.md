# 스토리·맵·퀘스트 콘텐츠 설계 폴더 (docs/design/story/)

> **무엇인가**: 이 게임의 **이야기(세계관·챕터 아크), 맵 컨셉·디자인, 퀘스트 라인**을 한 몸으로 설계·관리하는 폴더다.
> 세 축은 따로 놀지 않는다 — 챕터가 무대(맵)를 정하고, 무대가 퀘스트 동선을 정하고, 퀘스트가 대사를 부른다.
>
> **운영 방식**: 제작자 + 여러 AI 에이전트가 세션을 넘나들며 공동 보완한다 (⚖️ 2026-08-14 제작자 지시).
> 아래 §3 협업 규약을 지키면 어떤 에이전트든 맥락 없이 이어서 작업할 수 있다.

## 3. 협업 규약 (모든 에이전트 공통)

1. **표기**: ⚖️ 제작자 확정(변경 금지) / 🧭 에이전트 제안(자유 보완·반박 가능) / ❓ 열린 질문·미실측 / ✅ 게임 데이터 반영됨. 확정·반영·제안에는 **날짜**를 남긴다.
2. **⚖️ 항목은 제작자 승인 없이 바꾸지 않는다.** 🧭 제안을 고칠 때는 기존 제안을 지우지 말고 **대안을 나란히** 적는다 — 선택은 제작자가 한다.
3. **하드 제약 위반 콘텐츠 금지**: 퀘스트 조건 10종, 아이템 영문 `Name` 키, 대사 규칙(40자·이모지 금지)은 [quest-design.md](./quest-design.md) §1이 요약한다. 시스템에 없는 것이 필요하면 콘텐츠에 섞지 말고 **"시스템 제안"으로 분리 표기**한다.
4. **❓가 붙은 가정은 반영 전에 실측한다** (해당 `.mlua`/패키지 코드 확인). 미검증 가정을 CSV에 넣지 않는다.
5. **대사 집필은 [npc-cast.md](./npc-cast.md) 말투 카드와 [story-bible.md](./story-bible.md) §0 톤 가드를 따른다.** 카드에 없는 NPC 대사를 쓰려면 카드부터 추가한다.
6. **CSV 반영 시** [quest-design.md](./quest-design.md) §5 체크리스트 + AGENTS.md §8 검증 절차를 수행하고, 이 폴더 진행 보드(§2)와 [docs/tasks.md](../../tasks.md)에 기록한다.
7. 이 폴더는 `docs/**` — 직접 편집 가능 레인이다. 맵·모델·UI를 만질 때는 각 빌더 규칙(AGENTS.md §5)이 그대로 적용된다.
