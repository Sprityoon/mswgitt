## 2. 우리 프로젝트의 4분면 UI 매핑 규약

1. **Diegetic (게임 세계 속 실재)**
   - 플레이어가 직접 체감할 수 있는 월드 오브젝트 상태 변화로 수치를 대체.
   - *모닥불/화로*: 연소 시간에 따른 불꽃 크기와 연기 파티클 단계적 변화.
   - *작물 및 묘목*: 4단계 성장 스프라이트(`SpriteRUID`)를 통해 수확 적기 직관 안내.
   - *도구 내구도*: 파손 단계별 손에 든 도구 스프라이트 미세 균열.

2. **Non-Diegetic (2D 고정 HUD)**
   - 앤틱 우든 프레임 + 골드 림 + 양피지 톤앤매너 고정.
   - *좌상단*: 프로필/레벨 + HP/MP 바 + 퀘스트 트래커 위젯.
   - *하단 중앙*: 10칸 슬림 퀵슬롯 핫바 (도구 내구도 + 소모품 수량).
   - *우하단*: 메인 액션 대형 버튼(`Ctrl`) + 아치형 스킬 4슬롯(`QWER`) + 점프(`Alt`)/상호작용(`F`).
   - *우상단*: 날씨/시간 위젯 + 나침반 미니맵 + 가방(`I`)/제작(`C`) 퀵 토글.

3. **Spatial (월드 좌표계 투영 UI)**
   - *조준 셀 프롬프트*: 플레이어가 바라보는 타겟 셀(Footprint ∩ Aim Cell)에 뜨는 `[F]` 상호작용 말풍선.
   - *데미지 스킨*: 타격 발생 시 몬스터 위치에서 튀어 오르는 타격 폰트와 크리티컬 이펙트.
   - *몬스터 미니 HP바*: 타격받은 몬스터 머리 위에만 3초간 표시되는 체력 게이지.

4. **Meta (화면 렌더 연출)**
   - *위기 체력*: 체력 25% 이하 시 화면 테두리가 붉게 고동치는 비네팅(Vignette) 펄스 연출.
   - *날씨 연출*: 폭설/한파 시 화면 가장자리 서리 오버레이, 폭우 시 물방울 맺힘 효과.
   - *야간 램프 시야*: 램프를 들지 않은 밤에는 시야 반경을 제외하고 화면을 어둡게 가리는 마스크 처리.

## 3. 인지 부하 억제 (Zero Extraneous Load) 실천 규칙

- **PC/모바일 단일 레이아웃 준수**: 플랫폼별 동적 분기를 금지하고 단일 고정 레이아웃을 사용하여 기기 전환 시에도 플레이어의 근육 기억(Muscle Memory)과 멘탈 모델을 유지한다.
- **모바일 최소 터치 타겟 규격**: 모든 버튼 및 탭 요소는 최소 **88×88px**을 상시 준수하여 조작 실패로 인한 피로를 원천 차단한다.
- **월드 직접 클릭 금지 원칙**: 월드 오브젝트 직접 클릭/터치를 배제하고 오직 **조준 셀 + `F` 키(PC) / `BtnInteract`(모바일)** 체계로 통일하여 UI 창과의 클릭 충돌을 완전히 제거한다.
- **신속하고 명확한 피드백 루프**: 버튼 누름, 아이템 습득, 스킬 시전은 0.1초 내 비주얼(스프라이트 변화) + 청각(효과음)으로 반응해야 한다.

## 4. 정보 역피라미드와 상황 반응형(Contextual) HUD

- **평상시 (탐색 모드)**: 체력이 완충 상태일 때 HP 게이지를 은은하게 페이드아웃하여 화면 개방감과 아늑한 생활 톤을 살린다.
- **전투/위기 상황**: 첫 타격이나 피격 즉시 HP/MP 게이지와 스킬 쿨다운 클러스터를 100% 불투명도로 즉각 활성화한다.
- **메뉴 열림 시**: 인벤토리(I)나 제작(C) 등 전략 메뉴가 열리면 주변 HUD의 우선순위를 낮추고 모달 포커스를 안전하게 보호한다.

## 5. 접근성 (XAG) 표준 준수 체크포인트

- **색약 배려 (다중 채널 전달)**: 색상만으로 등급이나 상태를 표현하지 않고, 아이콘/텍스트/효과음을 반드시 1:1 결합한다.
- **4.5:1 이상 고대비 텍스트**: 양피지 배경과 어두운 갈색 글자 간 높은 명도 대비를 유지하고, 월드 상단 텍스트는 2px 이상의 아웃라인(외곽선)을 필수 적용한다.
- **단일 탈출 경로 (ESC / Close Button)**: 모든 창과 모달은 `ESC` 키 및 우상단 `[X]` 닫기 버튼으로 일관되게 닫혀야 한다 (`UIManager` LIFO 스택).
