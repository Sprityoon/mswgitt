# UI 캡처 (2026-10-14, PC 플랫폼)

- 방식: Maker Play 중 `maker_execute_script`로 각 UI의 **실제 열기 함수**를 호출하고 `maker_screenshot`으로 캡처. 저장 데이터를 바꾸는 호출(삭제·수락·제출·구매 등)은 하지 않았다.
- 플랫폼: PC (`IsMobilePlatform() == false`), 시뮬레이션 해상도 1920×1080, **캡처 파일은 896×504**(Maker 게임 뷰 크기에 따라 정해진다).
- 캐릭터: 슬롯 1 `eeee` (Lv.25 트래퍼). 마을(town)에서 대부분 촬영, 영지(Home_*)에서 일부.
- 열린 직후에는 페이드 애니메이션 중이라 반투명하다. 아래 파일은 모두 완전히 열린 뒤 장면이다.

## 화면에서 보인 문제 후보 (눈으로 본 것, 원인 미확인)

1. **스킬트리**: 회색 어두운 크롬(다른 창의 나무/종이 톤과 다름). 창 아래쪽이 화면 밖으로 잘리고 퀵슬롯과 겹침. 오른쪽 상세 패널이 HUD 버튼 위에 겹침.
2. **연구소**: 목록이 창 아래로 삐져나옴. 완료 안내 문구가 말줄임.
3. **포탈 목록**: 아래쪽이 퀵슬롯과 겹침.
4. **도감**: 카테고리 탭 하나가 영문 `equipment`로 표기.
5. **의뢰 게시판**: 부제 줄 일부가 목록에 가려짐.
6. **영지 권한 창**: 영지 안에서도 본문이 비어 있음(다른 플레이어가 없을 때 빈 상태 안내 없음).
7. **플레이어 상호작용 창**: 닫기 X가 제목 줄을 침범, 힌트 문구가 말줄임. **영지 초대 창과 같은 자리에 겹쳐 뜸**(첫 시도에서 확인).
8. **퀘스트 '완료 가능' 빈 상태**: 안내 문구가 잘림.
9. **화로**: 진행 화살표가 흰 막대로 보임.
10. **낚시 게이지**: 값을 넣어도 두 막대가 모두 흰색으로 꽉 참(강제 호출이라 실제와 다를 수 있음).
11. **채팅 펼침**: 탭 글자가 글자 단위로 줄바꿈(`전 체`, `귓 속 말`, `시 스 템`).
12. **테스트 키 목록 HUD**: 글자가 박스 밖으로 넘침.
13. **외형 꾸미기**: 좌우 화살표 버튼이 글리프 없는 갈색 원으로 보임(내 캐릭터 유지 모드에서는 `<` `>` 표시).
14. **이름짓기**: 입력창 안내 글자가 매우 흐림.
15. **가방 첫 열림**: 아이콘이 흰 네모로 보이는 순간이 있음(비동기 아이콘 로딩, 잠시 뒤 정상).
