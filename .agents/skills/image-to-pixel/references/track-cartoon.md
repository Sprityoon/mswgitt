# 트랙 A — 메이플 카툰 채색을 코드로 그리고 '살짝 도트화'로 마감 (propkit)

공식 MapleStory 월드 오브젝트(냄비·등불·상자·건물)와 **커스텀 도트 지형(64px 타일)** 사이에 섞여도 티가 나지 않는 소품을 그리는 방법. 형태·명암은 메이플식 채색(부품 도형·셀 명암·짙은 갈색 외곽선)으로 잡고, **마지막에 지형과 같은 도트 밀도로 도트화**한다(⚖️ 제작자 2026-09-29 "이미지는 약간 도트화 + 디테일은 더 쌓아서"). 채색만 납품하면 도트 지형 위에서 떠 보인다.

## 0. 도트 마감 규격 (먼저 정한다)

- 지형 도트 = 64px 타일이 화면 100px → **1도트 ≈ 화면 1.56px**. 소품도 1도트가 화면 1.5px 안팎이 되게: `dot = round(1.5 / 모델 Scale)` (Scale 0.75 → 2, 1.0 → 2(약간 굵게), 0.5 → 3).
- `export(path, dot=dot, colors=64~80)` — ① dot 격자로 축소 ② 알파 이진화 ③ 팔레트 제한(메디안 컷, 디더 없음) ④ 실루엣 테두리 1도트 selout ⑤ 원래 크기로 NEAREST 복원. 캔버스·피벗은 그대로.
- **도트화에서 살아남게 그리기**: 디테일 최소 2도트 · 외곽선 폭 ≈ 1도트(dot 2 면 2.2px) · 안쪽 선 ≈ 0.9도트 · 반투명 연기/번짐 대신 **불투명 덩이 연기, 표면에 칠한 빛**.
- 외부 이미지 생성 AI 결과물도 같은 마감: `python scripts/propkit.py pixelize in.png out.png --dot 2 --colors 72 --width 256`.

## 1. 매체: 부품 마스크 + 4× 슈퍼샘플

- 에셋마다 `docs/design/art/<asset>/draw_<asset>.py` 하나. `draw(state)` 가 `Canvas` 를 돌려주고, `main()` 이 상태별로 export 한다. **다시 돌리면 같은 PNG** — 수정은 항상 스크립트에서.
- `Canvas(W, H, ss=4)` — W×H 는 **최종 PNG 크기(논리 px)**. 모든 좌표·두께도 논리 px. 내부는 4배로 그리고 `export()` 가 프리멀티 알파로 한 번 줄인다(검은 테두리 번짐 없음).
- 도형은 **마스크('L' 이미지)** 로 만든 뒤 칠한다. 마스크끼리 합/교/차가 되므로 "벽돌은 몸통 안에만", "불꽃은 아궁이 안에만" 같은 클리핑이 한 줄이다.
- 반복 디테일(벽돌·이음새·나이테)은 `ImageDraw` 로 별도 RGBA 레이어에 한꺼번에 그리고 **알파를 몸통 마스크와 곱해** 합성한다(부품마다 전체 캔버스를 합성하면 느리다).

### propkit API 요약

| 분류 | 함수 | 메모 |
|---|---|---|
| 마스크 | `ellipse` `circle` `rect(r=)` `poly` `arch(cx,bottom,half_w,top)` `dome(cx,bottom,hw_base,hw_top,shoulder_y,top)` | 아치 = 아궁이·문, 돔 = 가마·오두막 몸통 |
| 연산 | `union` `intersect` `subtract` `shift` `grow(r)` `shrink(r)` `soften(r)` | grow/shrink 는 둥근 팽창·침식(블러+임계값) |
| 칠 | `paint(m, color, alpha)` `gradient(m, c0, c1, angle)` `radial(m, c_center, c_edge, cx, cy, r)` | 색에 알파를 넣으면(`#rrggbb00`) 그 방향으로 사라지는 그라데이션 |
| 부품 | `part(m, fill, outline, width)` | 외곽선 밑칠 + 채움. `fill` = 색 또는 `(위색, 아래색[, 각도])` |
| 명암 | `shade(m, color, dx, dy, blur, alpha)` · `light(...)` · `glow(m, color, r, alpha)` | 광원 = (-dx,-dy) 방향. shade 는 반대편 초승달, light 는 광원쪽 림 |
| 모양 | `flame_points(cx, base, w, h, lean)` | 물방울형 불꽃 윤곽 |
| 출력 | `nudge(dx)` · `export(path)` → `{bbox, bottom_margin, center_x_offset}` · `preview_sheet(items, out)` | preview 는 게임 배율 × 배경 4종 |

## 2. 빛·명암 모델 (한 에셋 안에서 절대 섞지 않는다)

광원 **좌상단 고정**. 부품마다 아래 순서로 올린다:

1. **바탕**: 위→아래 2색 그라데이션 (위가 밝고 따뜻함). 큰 덩어리엔 `gradient(body, "#fff2dc", "#7a3220", 90, alpha=0.22)` 같은 **오버레이**를 한 번 더.
2. **형태 그늘**: `shade(m, deep, dx=+, dy=+, blur=덩치의 8~10%, alpha 0.4~0.5)` — 넓고 부드럽게 한 번, 좁고 진하게(`blur` 작게, `alpha` 0.3) 한 번.
3. **림라이트**: `light(m, 크림/흰색, dx, dy, blur, alpha 0.35~0.55)` — 좌상단 가장자리만.
4. **바닥 AO**: 부품 아래 16~18px 을 `#색00 → #색` 그라데이션(alpha 0.45~0.5)으로 눌러 접지감.
5. **스페큘러**(유광 재질만): 작은 흰 타원 1~2개, alpha 0.6~0.8.

## 3. 외곽선

| 캔버스 긴 변 | 바깥 외곽선 | 안쪽 선(이음새·줄눈) |
|---|---|---|
| ~128 | 1.6~2.0px | 1.0~1.2px |
| ~256 | 2.4~3.0px (도트 마감 dot 2 면 **2.2px = 1도트**) | 1.4~2.0px (dot 2 면 1.8px) |
| ~512 | 4~5px | 2.5~3px |

도트 마감을 하면 외곽선은 **1도트**가 기준이다 — 더 굵으면 도트화 후 2도트 선이 되어 지형 도트보다 무겁다. 실루엣 테두리는 `pixelize` 의 selout 이 한 번 더 정리한다.

- 기본색 `#4a2a1c`(따뜻한 짙은 갈색). 식물은 `#3f6424`, 어두운 내부(아궁이 안 숯)는 `#1a0b06`, 흰 꽃잎은 `#6b5a3a` 1px.
- **공식 이웃과 두께 비교는 게임 배율에서** 한다 — 캔버스에서 적당해 보여도 Scale 0.75 에선 얇아지고, 확대 배율이면 굵어진다.

## 5. 발광·상태 연출

- **발광 부품은 주변을 물들인다**: 불꽃이 있으면 가까운 돌·받침·몸통 하단에 `radial(주변 합집합, "#ffcf6a", "#ffcf6a00", 광원 위치, r≈80, alpha≈0.6)`.
- **대기(꺼짐) 상태도 '죽은' 느낌이 아니게**: 숯 틈 불씨 선(`#ff8a3a` 1.3px) + 바닥 온기 radial alpha .55 — 힐링 톤 유지.
- **상태 짝 규칙**: 같은 `draw(state)` 안에서 `if lit:` 분기만. 캔버스·피벗·`nudge` 동일. 연기처럼 위로 솟는 요소 때문에 캔버스를 키워야 하면 **두 상태 모두** 같은 캔버스를 쓴다(대기 상태는 위가 비어도 된다).

## 6. 아이콘 파생

인벤토리 아이콘은 대표 상태(보통 가동)를 bbox 로 잘라 **128×128 안 112px 에 맞추고 1px 아래로** 둔다. 작은 크기에서 뭉개지는 디테일(줄눈 등)은 괜찮다 — 실루엣과 대표색(불빛)이 읽히면 된다.

## 6-bis. 디테일 쌓기 (제작자 확정 — "디테일이 살아 있어야")

큰 형태를 먼저 잡은 뒤 아래 층을 **부품마다** 하나 이상 올린다. 화로 v2 가 쓴 목록:

| 층 | 예 (화로) |
|---|---|
| 재질 편차 | 벽돌 6톤 + 그을린 벽돌 12% + 밝은 벽돌 10% · 돌마다 다른 톤 · 받침 블록별 톤 |
| 결·손상 | 벽돌 윗면 하이라이트/아랫면 그늘 · 줄눈 음영(파인 홈) · 깨진 모서리 · 금 · 돌 표면 점 · 나무껍질 결 · 나이테·마른 틈 |
| 쓰던 흔적 | 아궁이 위 그을음 · 굴뚝 입구 그을음 · 재 바닥 · 숯 틈 불씨 |
| 공예 디테일 | 리벳 박힌 쇠띠 · 쇠 문턱 · 들여다보는 구멍(가동 시 발광) · 쐐기돌 불꽃 문양 · 굴뚝 돌 캡 |
| 생활 소품 | 장작더미 + 꽂힌 돌도끼 · 산출물(구리 주괴 더미) |
| 자연 포인트 | 이끼 모자 + 늘어진 이끼 + 잎결 3톤 · 꽃 5송이 · 새싹 · 버섯 · 이끼 한 줌 |

- 좌우 무게: 한쪽 소품(장작더미)은 반대쪽 소품(주괴·버섯)과 굴뚝으로 맞추고 `nudge` 로 중심 정렬.
- 디테일이 늘수록 **덩어리 명암(형태 그늘·림)이 디테일보다 강해야** 실루엣이 산다 — 디테일은 명암 위에 얹는 것이지 대체가 아니다.

## 7. 자가비평 체크리스트 (매 렌더, 최소 2회)

`preview_sheet(..., tiles={"grass": "tileimg/FullGrass.png", ...})` 로 **게임 배율 × 실제 지형 타일 + 모래·눈·체커 × 이웃 에셋** 시트를 만들어 본다. 1:1 확대(NEAREST ×2)로 도트 결함도 따로 본다.

0. **도트 밀도**: 실제 지형 타일 위에서 소품 도트와 풀 도트가 같은 굵기로 보이는가? 도트화 전 원본과 비교해 사라진 디테일은?

1. **실루엣**: 게임 배율에서 한눈에 무엇인지 읽히는가 (눈 가늘게 뜨기)?
2. **이웃 톤**: 공식 에셋 옆에서 채도·명도·외곽선 두께가 같은 세계인가? 혼자 튀면 채도/외곽선부터 조정.
3. **빛 방향**: 모든 부품의 림은 좌상단, 그늘은 우하단인가?
4. **재질 구분**: 벽돌·돌·나무·식물·불이 서로 다른 재질로 읽히는가? (같은 톤으로 뭉치면 램프 간격 조정)
5. **가장자리**: `export()` bbox 로 위·좌우 여백 ≥ 2px — 잘린 연기·가지 없음?
6. **피벗**: `bottom_margin` 0~2, `center_x_offset` |≤2| (벗어나면 `nudge`)?
7. **상태 짝**: 대기↔가동을 번갈아 보면 발광·연기만 바뀌고 몸체는 1px 도 안 움직이는가?
8. **금지 사항**: 순검정 외곽선 없음 · 바닥 그림자 없음 · 무드(힐링/귀여움)에 반하는 요소 없음?

같은 결함이 두 번 살아남으면 부품 구성(실루엣) 단계가 틀린 것 — 그 단계로 돌아간다.
